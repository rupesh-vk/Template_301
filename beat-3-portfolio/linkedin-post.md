I opened a pull request to add 89 Australian Suzuki motorcycle dealer locations to AllThePlaces, an open source project that collects location data. Using Python and help from OpenAI Codex, I built an importer that turns dealer information into structured records for mapping applications.

A reviewer independently confirmed the 89 dealers across every Australian state and territory. The PR is still open, with one requested correction to how full addresses are stored.

The most useful lesson was learning what it takes to make a contribution reviewable. Beyond writing code, I had to check the results against the source, explain exactly what I tested, and revise claims that were unclear.

This gave me practical experience working in an existing codebase and using AI assistance while keeping the work grounded in evidence.
